# Demo script — Ardoise

Aim for about two minutes. Stay under three. Record the phone screen, or a 390px-wide browser window. Speak in English. No copyrighted music. Do not invent customers beyond what you type on camera. The notebook starts empty.

## Before you record

1. Open the live site, or run `npm run dev` and use the local URL.
2. Clear the site data for Ardoise so the notebook is blank.
3. Set the language to English with **EN** if you want the labels in this script. The sentence itself stays in French. That is the point.
4. Have WhatsApp available if you want the draft to open. You do not have to send the message. If you would rather not show a personal WhatsApp account, stop when the button and its link are visible, or use a desktop window where WhatsApp asks you to continue.

## Script

### 0:00–0:15 — The problem

Show a blank frame, or the empty Ardoise screen.

> In Togo, small shops sell on credit. Debts live in a paper notebook. It gets lost, and asking someone to pay feels awkward.

### 0:15–0:25 — The name

Show the slate at the top. It says **Ardoise** and **0 F CFA** / **On the slate**.

> This is Ardoise, a credit notebook for that shop. It stays on the phone. There is no account.

### 0:25–0:55 — One sentence

Tap an example, or type:

`Kofi a pris 2 sacs de riz 15000, payé 5000`

Tap **Read the sentence**.

> I type one sentence, the way the shopkeeper would say it. Ardoise finds Kofi, 15 000 total, 5 000 already paid, and 10 000 still due.

Point at the big figure. If a field is wrong, fix it. Then tap **Note it**.

### 0:55–1:15 — The balance

Show Kofi in the list, then open him.

> Kofi is on the slate for 10 000 F CFA. The history is the line I just noted. If I close the page and come back, he is still there.

Reload once, so that is visible.

### 1:15–1:35 — The reminder

Tap **WhatsApp reminder**. Let the draft appear. Do not send it unless you want to.

> One tap opens a polite reminder. I still send it myself. The same button in French says “Rappel WhatsApp”.

Switch **FR** for two seconds if you have time, then come back with **EN**. Go back without sending.

### 1:35–1:55 — A payment

Tap **Payment received**, then **Note the payment**. The slate goes to **0 F CFA** and **Settled**. The reminder becomes **Nothing to remind**.

> When Kofi pays, I note it. The balance drops. I am not chased to remind someone who owes nothing.

### 1:55–2:15 — Close

> The reading works with no API key. The plan is in the repository: scope, a product description, and a technical spec, written with the Devpost Learn skills before the build. Ardoise: no more lost notebooks.

Stop. Do not add a tour of the code. The judges are watching the phone.
