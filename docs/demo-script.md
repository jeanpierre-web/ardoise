# Demo script — Ardoise

Aim for about two minutes. Stay under three. Record the phone screen, or a 390px-wide browser window. Speak in English. No copyrighted music. The four people in the example shop are labelled sample data. Do not present them as real customers. The app has no users yet.

## Before you record

1. Open the live site, or run `npm run dev` and use the local URL.
2. Clear the site data for Ardoise so the first screen is the empty slate.
3. Set the language to English with **EN** if you want the labels in this script. The sentence itself stays in French. That is the point.
4. Have WhatsApp available if you want the draft to open. You do not have to send the message. If you would rather not show a personal WhatsApp account, stop on the preview. Do not tap **Open in WhatsApp**.

## Script

### 0:00–0:15 — The problem

Show the empty Ardoise screen: the chalk name, **0 F CFA**, and **Try with an example shop**.

> In Togo, small shops sell on credit. Debts live in a paper notebook. It gets lost, and asking someone to pay feels awkward.

### 0:15–0:35 — An example shop

Tap **Try with an example shop**. Point at the total, then at Kofi and Ama at the top (**Overdue**), then at Afi (**Settled**). Point at the banner that says this is example data.

> This is Ardoise. One tap loads a labelled example shop, so you can see a balance before you type anything. Overdue names sit first. I can clear the sample.

Tap **Clear the example**. The slate returns to zero.

### 0:35–1:05 — One sentence

Type, slowly enough that the marks appear:

`Kofi a pris 2 sacs de riz 15000, payé 5000`

Point at the marks, then at the card: Kofi, the rice, 15 000, 5 000 paid, 10 000 still due, and **Clear reading**.

> I type one sentence, the way the shopkeeper would say it. Ardoise marks what it found, on this phone, with no account and no API key.

Change a field if you want to show that it can be fixed. Tap **Read the sentence**, then **Note it**. The figure on the slate counts up to 10 000.

### 1:05–1:20 — The balance

Show Kofi in the list, then open him. Reload once.

> Kofi is on the slate for 10 000 F CFA. If I close the page and come back, he is still there.

### 1:20–1:40 — The reminder

Tap **WhatsApp reminder**. Stay on the preview. Read the message. Do not send it unless you want to.

> The reminder is written for me. I still send it myself.

Switch **FR** for two seconds if you have time, then come back with **EN**. Close the preview without sending.

### 1:40–2:00 — A payment

Tap **Payment received**, then **Note the payment**. Wait for the figure to reach **0 F CFA**, the green **Settled**, and **Account cleared.** The reminder becomes **Nothing to remind**.

> When Kofi pays, I note it. The balance drops. I am not asked to remind someone who owes nothing.

### 2:00–2:15 — Close

> The reading works with no API key. The plan is in the repository: scope, a product description, and a technical spec, written with the Devpost Learn skills before the build. Ardoise: no more lost notebooks.

Stop. Do not add a tour of the code. The judges are watching the phone.
